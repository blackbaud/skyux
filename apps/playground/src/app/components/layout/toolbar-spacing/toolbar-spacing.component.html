Toolbar / filter bar / list summary padding

The toolbar, filter bar, and list summary each bake in their own inset padding. That padding is only correct when the component is flush inside a layout="list" page or tab. Anywhere else it stacks on top of the padding the parent container already provides, so the component's contents sit indented from everything around them.

The dashed red line marks the container's content edge. Anything that starts to the right of it is misaligned.
