Input box with signal forms

Every control below is bound with the [formField] directive from @angular/forms/signals. Choose Mark all as touched to reveal the validation messages that sky-input-box renders from the signal-forms field state.

Native controls

The control types allowed inside an input box are listed in libs/sdk/skyux-eslint/src/rules/template/utils/input-box-types.ts.

SKY components

These components are ControlValueAccessor-based. [formField] reaches them through the interop NgControl it provides, but that interop control is not an AbstractControl. All the components below now guard against that, so they work with [formField]; one small remaining behavior difference is noted inline.

Validators

Input box renders required, email, minLength, and maxLength errors automatically, and renders any other error that carries a message. Errors without a message need a sky-form-error in the input box content.
